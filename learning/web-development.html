HOW THE WEB WORKS

From a blank screen to an experience people can use.

Web Development combines structure, visual design, interaction and logic to create websites and web applications that people use through a browser.

You learn how frontend interfaces connect with backend systems, databases and APIs to create complete, responsive and reliable digital products.
