10 / RECURSION

A function can call
itself to solve smaller problems.

Recursion becomes simple when you see each call as one smaller version of the same problem.

FUNCTION 
def countdown(n):
    if n == 0:
        return

    print(n)
    countdown(n - 1)
CALL 01countdown(3)
CALL 02countdown(2)
CALL 03countdown(1)
BASE CASEcountdown(0)
